# Press kit

Store page and promotional material for Blank Canvas. Nothing here is
loaded by the game — the folder carries a `.gdignore` file, so Godot skips
it during import and leaves it out of the exported builds.

Store page: https://nokigamerhd.itch.io/blank-canvas

## screenshots/

Store screenshots, in the order they appear on the page.

| File | Screen |
|---|---|
| `01-main-menu.png` | Main menu over the animated painted background |
| `02-character-creator.png` | 36×36 character editor with palette and brush |
| `03-ability-creator.png` | Ability editor with the pixel budget |
| `04-arena-gameplay.png` | Arena mid-run, canvas already painted |

## promo/

| File | Size | Use |
|---|---|---|
| `cover.png` | 1408×1117 | Store cover art (itch.io crops it to 630×500) |
| `icon-256.png` | 256×256 | Application and favicon icon |
| `page-background.png` | 1280×960 | Store page background; same image as `assets/backgrounds/menu_blurred_scene.png` |
| `banner-7680x4320.png` | 7680×4320 | Event banner for monitors, TVs and projectors |
| `banner-4320x7680.png` | 4320×7680 | Event banner for phones and portrait screens |

Both banners are generated by `scenes/test/banner_maker.tscn`, which renders the
background at full size with the game's own paint canvas (enemy trails, boss
explosions and projectile trails, with no sprites), then lays the logo, slogan
and credits over it. Run it with a display and the X11 driver:
`godot --display-driver x11 scenes/test/banner_maker.tscn`.
