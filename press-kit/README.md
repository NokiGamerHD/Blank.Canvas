# Press kit

Store page and promotional material for Blank Canvas. Nothing here is
loaded by the game — the folder carries a `.gdignore` file, so Godot skips
it during import and leaves it out of the exported builds.

Store page: https://nokigamerhd.itch.io/blank-canvas

## screenshots/

Store screenshots, in the order they appear on the page.

All six are 2560×1920: the game renders at 640×480, the screenshot harness
captures it at 1280×960, and the files are scaled ×2 with nearest-neighbour, so
every pixel stays square.

| File | Screen |
|---|---|
| `01-main-menu.png` | Main menu over the animated painted background |
| `02-character-creator.png` | 36×36 character editor with palette, brush and the flask-slot shop |
| `03-ability-creator.png` | Ability editor with the pixel budget |
| `04-arena-gameplay.png` | Arena mid-run, canvas already painted, stats panel and flask bar |
| `05-boss-wave.png` | Boss wave: the magenta square with its aura and the boss health bar |
| `06-upgrade-shop.png` | The 5-wave shop with a golden perk and two pink character upgrades |

Regenerate them by running `scenes/test/screenshot_harness.tscn` with a display
and scaling the prints it leaves in `user://screenshots` (see `TESTING.md`).

## promo/

| File | Size | Use |
|---|---|---|
| `cover.png` | 1408×1117 | Store cover art (itch.io crops it to 630×500) |
| `icon-256.png` | 256×256 | Application and favicon icon |
| `page-background.png` | 1280×960 | Store page background; same image as `assets/backgrounds/menu_blurred_scene.png` |
| `banner-7680x4320.png` | 7680×4320 | Event banner for monitors, TVs and projectors |
| `banner-4320x7680.png` | 4320×7680 | Event banner for phones and portrait screens |
| `poster-a4-2480x3508.png` | 2480×3508 | Printable A4 poster (300 DPI) with both QR codes |
| `QR-Jogo.png` | 500×500 | QR code to the itch.io page, used by the poster |
| `QR-Insta.png` | 500×500 | QR code to the Instagram profile, used by the poster |

All three banners are generated by `scenes/test/banner_maker.tscn`, which renders
the background at full size with the game's own paint canvas (enemy trails, boss
explosions and projectile trails, with no sprites), then lays the logo, slogan
and credits over it. Run it with a display and the X11 driver:
`godot --display-driver x11 scenes/test/banner_maker.tscn`. Every layout is
seeded, so a re-run reproduces the same three files byte for byte.

The A4 poster is the portrait banner re-laid out for print: 2480×3508 is exactly
A4 at 300 DPI, and it adds the two QR cards above the credit line, each labelled
in the game's font. The codes are stamped at an integer ×2 of the 500×500
sources, so the modules stay square and the codes scan as well as the originals;
replacing a QR means dropping a new 500×500 PNG over the old one and running the
maker again.
